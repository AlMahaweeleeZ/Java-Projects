Temperature Converter

A simple Java project that converts temperatures between Celsius and Fahrenheit. The program uses user input and conditional statements to determine the conversion the user wants to use.

Features:
- Converting between Celsius and Fahrenheit and vice versa
- Records temperature value the user enters
- Uses conditional logic to determine the selected conversion
- Displays converted temperature

Concepts Demonstrated:
- Variables and data types
- Arithmetic operations
- if/else if conditional statements
- Scanner for user input
- Basic program flow and user interaction

This was coded using Eclipse IDE for Java.
